# Bank Account Application

## Overview
This project is a React-based banking interface built to practise component-based architecture and state management.

## Features
- Create and manage account balance  
- Input validation and error handling  
- Dynamic UI updates based on user actions  

## What I Learned
- Managing state in React  
- Structuring components for reuse  
- Handling user input and validation  
- Writing cleaner, more maintainable JavaScript  

## Tech Used
- React  
- JavaScript (ES6)  
- HTML, CSS
